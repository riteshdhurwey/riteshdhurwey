# Hi 👋 I'm Ritesh Dhurwey

Backend-focused engineering student passionate about building reliable and scalable software. I enjoy working with Go, C++, Linux, and PostgreSQL to develop APIs, backend services, and infrastructure-oriented applications.

Built **SysMon**, a real-time Linux monitoring tool that collects and analyzes system metrics directly from the `/proc` filesystem. Currently building a **Review Fraud Detection API** using Go and PostgreSQL to explore backend architecture, database design, and fraud detection techniques.

* 🔭 Currently working on: **Review Fraud Detection API**
* 🌱 Learning: **Go, PostgreSQL, Docker, and System Design**
* 💡 Interested in: **Backend Engineering, Distributed Systems, and Infrastructure Software**
